# Contributing to Simple Interest Calculator

First off, thank you for taking the time to contribute! 🎉

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the source code or scripts, please open an issue and include:
* Your operating system and terminal environment.
* Steps to reproduce the bug.
* Any error messages encountered.

### Suggesting Enhancements
If you have an idea to improve the project (like adding new features or improving script performance), feel free to open an issue or submit a pull request.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
